# Portfolio (static, GitHub Pages)
Files: index.html, styles.css, script.js, fonts/, assets/, Vineela_Therala_Resume.pdf. No build step, no backend, no keys.
**Preview:** double-click index.html, or run `python3 -m http.server 8000` here and open http://localhost:8000
**Deploy (keeps your URL):** open github.com/theralavineela/theralavineela.github.io > Add file > Upload files > drag in everything in this folder (keep the fonts and assets folders) > Commit to main. Settings > Pages should read "Deploy from a branch: main, / (root)". Wait 1 to 3 minutes, then hard-refresh (Ctrl+Shift+R).
**Roll back:** keep a copy of the old index.html first, or use the repo's Commits list to restore.
**Edit text:** change index.html. Edit colours at the top of styles.css (:root).
